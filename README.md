# Lake Village Belarus

Интерактивная концепция загородного курорта Lake Village. Тур запускается по кнопке и работает в одном облегчённом режиме. Доступны общий обзор, автотур, прогулка от первого лица, день и вечер, а также отдельный просмотр генерального плана.

Первый этап архитектурной визуализации включает два демонстрационных дома. A-Frame находится на левом берегу, Barnhouse на правом. В каждом можно рассмотреть фасад, террасу и сауну, а также зайти в гостиную. Остальные здания представлены в общей модели курорта. Точная посадка и планировки зависят от проектной документации.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8000
```

Откройте [3D-тур](http://localhost:8000/#explore). Для него нужен WebGL 2. В браузере без WebGL кнопка «Генплан» открывает схему из презентации. 3D-движок, модели, текстуры и HDRI загружаются из репозитория. Сайт также работает как статический проект на GitHub Pages.

В списке маршрута выберите **A-Frame 56** или **Barnhouse 56**. Кнопка **«Рассмотреть ближе»** переводит камеру к фасаду, **«Зайти внутрь»** открывает вид из гостиной. Для прогулки используйте WASD или стрелки и перетаскивайте вид мышью. На телефоне работают свайпы и экранные стрелки.

### Пересборка GLB

Для домов нужны Blender 4.3 и текстуры из репозитория. Выходные файлы включают текстуры и сохраняются в `assets/models`.

```sh
blender -b -t 4 --python-exit-code 1 --python tools/build_cabins.py
```

Для ландшафта скачайте 1K glTF-версии из реестра ассетов. Сохраните каждый glTF вместе с его BIN и текстурами в отдельной папке с идентификатором ассета, например `/path/to/sources/fir_sapling/fir_sapling.gltf`.

```sh
blender -b -t 4 --python-exit-code 1 --python tools/build_landscape.py -- /path/to/sources
```
